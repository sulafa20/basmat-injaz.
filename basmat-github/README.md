# بصمة إنجاز — GitHub Pages

هذه **بوابة عامة** لفتح لوحة النشاط المحمية، وليست نقلًا مباشرًا لبيانات المعلمات إلى GitHub.

## الإعداد

1. افتحي `index.html` في محرر نصوص، وابحثي عن `PASTE_YOUR_PRIVATE_APPS_SCRIPT_EXEC_URL_HERE`.
2. استبدلي النص برابط **تطبيق الويب** الحالي الذي ينتهي بـ `/exec` من Google Apps Script. لا تضعي رابط المحرر أو رقم تعريف النشر.
3. تأكدي من أن تطبيق Apps Script يعمل فعلًا من الرابط، وأن ملف HTML فيه اسمه `Index.html`.
4. في Google Apps Script: **Deploy > Manage deployments > Edit > New version > Deploy** عند تعديل الكود.
5. اضبطي **Who has access** على `Only myself` للتجربة الخاصة. لا تختاري `Anyone` أو `Anyone with Google account` مع وضع `Execute as: Me` لعرض بيانات المعلمات، لأن ذلك قد يسمح لغير المصرّح لهم بقراءة البيانات بصلاحيات مالك التطبيق.
6. افتحي GitHub، أنشئي مستودعًا باسم `basmat-injaz`، وارفعي `index.html` و`README.md` فقط.
7. في المستودع: **Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save**.
8. انتظري ظهور رابط GitHub Pages، عادة `https://USERNAME.github.io/basmat-injaz/`.
9. اختبري زر فتح لوحة المتابعة باستخدام الحساب الذي لديه الصلاحية.

## حدود مهمة

- لا يمكن لـ GitHub Pages تشغيل `Code.gs` أو `google.script.run` مباشرة.
- تبقى لوحة المعلمات والعدادات في Apps Script، وتفتح من زر GitHub في تبويب مستقل. هذا حل آمن وعملي لكنه **ليس نقلًا كاملًا للتطبيق إلى GitHub**.
- لا ترفعي ملف `Code.gs` أو قوائم المعلمات أو نسخ بيانات الشواهد أو رموز وصول Google إلى مستودع عام.
- الرابط إلى تطبيق Apps Script ليس سرًا أو وسيلة تحقق بحد ذاته؛ حماية البيانات تعتمد على إعدادات الوصول داخل Google Apps Script.
- في وضع `Only myself`، ستتمكن صاحبة الحساب المصرّح له فقط من استخدام اللوحة. إتاحة لوحة خاصة لعدة معلمات تتطلب تصميم مصادقة وصلاحيات مناسبًا قبل توسيع الوصول.
- لا تُحدّث واجهة GitHub بيانات Drive بذاتها؛ التطبيق المحمي هو الذي يقرأ الملفات ويحسب النتائج عند فتحه، وقد يستعمل تخزينًا مؤقتًا لمدة خمس دقائق.
